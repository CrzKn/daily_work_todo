# Daily Work Todo - 功能需求文档

> 基于现有代码结构梳理，覆盖所有已实现的功能模块。

---

## 1. 项目概述

**Daily Work Todo** 是一个轻量级个人任务管理系统，提供任务看板、标签管理、状态管理、优先级管理四大功能模块。

- **目标用户**：个人用户（单用户场景，无登录体系）
- **核心价值**：以看板直观展示任务在各状态下的分布，支持拖拽流转、标签归类、优先级标识
- **核心旅程**：进入系统 → 查看看板 → 新建任务 → 按状态/优先级/标签组织 → 拖拽流转状态

**角色与权限**：系统为个人使用，所有功能对所有使用者开放，无权限分级。

## 3. 系统功能模块

### 3.1 侧边导航

**功能描述**：
- 左侧固定侧边栏，展示系统标题「Daily Work Todo」和四个功能入口
- 点击模块切换右侧内容区
- 当前选中模块高亮（蓝底白字）

**模块列表**：
1. 任务看板
2. 标签管理
3. 任务状态管理
4. 任务优先级管理

---

### 3.2 任务看板（核心功能）

#### 3.2.1 看板概览

**功能描述**：
- 以看板（Kanban）形式展示所有任务，每一列对应一个任务状态
- 列按「任务状态管理」中的排序值升序排列
- 每列头部显示：状态名称、圆点色标、该状态下任务数量、收起/展开按钮
- 无分类的任务归入「未分类」列（灰色）
- 看板横向滚动，当状态数量超出视口宽度时可左右滑动

#### 3.2.2 任务卡片

**功能描述**：
- 每个任务以卡片形式展示在对应状态列下
- 收起模式下仅显示标题和创建日期
- 展开模式下额外展示内容摘要（截断为 60 字符）、优先级标签、标签
- 优先级标签根据优先级排序值动态计算颜色：数值越小越接近红色、越大越接近绿色
- 卡片可拖拽，拖拽时透明度降低，目标列高亮边框

#### 3.2.3 拖拽修改状态

**功能描述**：
- 卡片支持拖拽，拖动到目标状态列即可修改任务状态
- 拖动过程中若鼠标进入看板左右边缘（80px 以内），看板自动横向滚动，速度随距边缘距离递增（最大 20px/帧）
- 拖拽完成后保存状态变更，保存失败时回滚至原状态并提示
- 支持 ESC 键取消下拉、关闭弹窗

**业务规则**：
- 同一状态列内放置不触发更新
- 拖拽完成后刷新数据，任务按后端排序规则重新排列

#### 3.2.4 新建任务

**功能描述**：
- 点击右上角「+ 新建任务」按钮打开新建弹框
- 表单字段：任务标题（必填，最多 200 字）、任务内容（必填，多行文本）、优先级（可选）、标签（可选）
- 标题或内容为空时弹出提示
- 提交成功后自动刷新看板，任务卡片出现在默认状态列中

**系统自动处理**：
- 创建时间写入当前时刻
- 自动分配排序值最小的状态作为默认状态（无任何状态时不分配）
- 优先级/标签未选择时按未设置处理

#### 3.2.5 任务详情弹框

**功能描述**：
- 点击任意任务卡片弹出详情弹框
- 弹框字段：任务标题、任务内容、优先级（自定义下拉）、标签（下拉选择）、创建时间（只读）、更新时间（只读）
- 支持直接在弹框内编辑并保存

**优先级自定义下拉**：
- 触发器保持与普通输入框一致的视觉样式
- 展开后选项以与卡片相同的彩色胶囊展示（颜色规则与卡片一致）
- 支持选择「不设置」清除优先级
- 下拉面板跟随触发框定位，不被弹框滚动区域遮挡
- 点击外部遮罩、按 ESC 或弹框滚动时自动关闭下拉

**保存逻辑**：
- 保存成功后刷新看板数据，并同步弹框内的最新更新时间
- 优先级/标签未选择时按未设置提交

**删除确认**：
- 弹框底部有「删除」按钮
- 点击后弹出二次确认对话框
- 确认删除后从列表中移除并关闭弹框

#### 3.2.6 任务排序规则

看板任务列表按以下优先级排序：

1. 优先级排序值升序（数值越小越靠前，未设置优先级排最后）
2. 创建时间降序（新创建的靠前）
3. 更新时间降序（最近更新的靠前）

#### 3.2.7 快捷键

| 快捷键 | 触发场景 | 行为 |
|--------|----------|------|
| ESC | 删除确认弹框 | 取消删除 |
| ESC | 新建任务弹框 | 关闭弹框 |
| ESC | 优先级下拉展开中 | 关闭下拉 |
| ESC | 任务详情弹框 | 关闭弹框 |

### 3.3 标签管理

**功能描述**：
- 提供标签的增删改查
- 页面分为「新增表单」和「数据列表」两个面板

**字段**：
| 字段 | 标签 | 类型 | 必填 |
|------|------|------|------|
| tagName | 标签名称 | 文本 | 是 |

**列表展示**：ID + 标签名称 + 操作（修改/删除）

**业务规则**：
- 删除后不再出现在列表与任务卡片中
- 名称必填校验失败时弹出提示框

---

### 3.4 任务状态管理

**功能描述**：
- 提供任务状态的管理，决定看板有哪些列以及排列顺序

**字段**：
| 字段 | 标签 | 类型 | 必填 | 说明 |
|------|------|------|------|------|
| ptStatusName | 任务状态名称 | 文本 | 是 | |
| ptStatusOrder | 排序 | 数字 | 是 | 数值越小越靠前 |

**业务规则**：
- 列表按排序值升序展示
- 删除后不再出现在列表
- 不提供新增入口
- 删除状态需谨慎——若存在任务关联此状态，任务将归入「未分类」列

---

### 3.5 任务优先级管理

**功能描述**：
- 提供优先级管理，优先级决定看板卡片的显示颜色

**字段**：
| 字段 | 标签 | 类型 | 必填 | 说明 |
|------|------|------|------|------|
| priorityName | 优先级名称 | 文本 | 是 | 列表中显示彩色圆点 |
| priorityOrder | 排序 | 数字 | 是 | 数值越小越靠前/颜色越红 |

**颜色规则**：
- 根据排序值在最小-最大范围内插值，映射为 HSL 色相 0°→120°（红→绿）
- 显示效果与任务看板卡片上的优先级标签、详情弹框优先级下拉的颜色完全一致

**业务规则**：
- 列表按排序值升序展示
- 删除后不再出现在列表
- 不提供新增入口

---

## 4. 业务规则汇总

| 规则 | 说明 |
|------|------|
| 排序 | 任务、状态、优先级均按各自排序值升序；任务在同优先级内按创建/更新时间降序 |
| 颜色 | 优先级颜色由排序值插值计算（红→绿），不存储固定色值 |
| 删除-任务 | 删除后不可恢复 |
| 删除-标签/状态/优先级 | 删除后不再展示于列表与任务卡片 |
| 默认状态 | 新建任务自动进入排序值最小的状态 |
| 校验 | 必填项为空时阻止提交并提示 |

## 5. 界面交互细节

### 6.1 弹框

| 弹框 | 关闭方式 | 说明 |
|------|----------|------|
| 任务详情弹框 | 点击 ×、ESC、点击遮罩空白处 | 遮罩按下和抬起都在遮罩上才关闭，避免选中文字拖拽到弹框外误关 |
| 新建任务弹框 | 点击 ×、ESC、点击遮罩空白处 | 同上方遮罩关闭逻辑 |
| 删除确认弹框 | ESC、点击遮罩 | 简单确认框 |
| 优先级下拉 | 点击外部、ESC、滚动弹框内容 | 透明遮罩覆盖弹框内部区域 |

### 6.2 边缘自动滚动

- 触发区域：看板容器左右各 80px
- 速度：距边缘越近越快，最快 20px/帧
- 终止条件：鼠标移出触发区、拖拽结束、到达可滚动边界
- 额外保护：纵向离开看板区域 60px 以外时也停止

### 6.3 表单校验

| 页面 | 校验方式 | 提示方式 |
|------|----------|----------|
| 标签/状态/优先级管理 | 必填校验 | 弹框提示 |
| 任务看板新建 | 必填校验 | 顶部消息条 |
| 任务详情保存 | 无额外校验 | 直接保存 |
